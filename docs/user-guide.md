# 本地 MOD 浏览器

> 本文描述公开版 2.5.0/70 操作契约。公开仓只带虚构演示数据；自动化测试只使用
> `test-results` 下的隔离副本。

双击本目录的 **启动MOD浏览器.cmd** 即可使用。它启动本机服务并打开默认浏览器，
重复双击会复用同一正式服务。

## 日常挑选

“AI 与任务中心”可连接外部助手、建立整理任务、查看执行状态、下载交接包、预览导入资料和按批次撤销。资料问题检查在后台进行；检查结果会注明是否过期。完整操作与备份恢复见 [AI 平台指南](ai-platform-guide.md)。

1. 左边选游戏，也可跨游戏搜索。搜索涵盖作者、说明、文件名和中文译文；`/` 快捷键聚焦搜索。
2. 用途、标签、作者、成人标记、翻译状态和作者更新时间可以组合；标签可分别选择“全部包含、任一包含、排除”，排除优先。当前条件可命名保存，和收藏、搭配分别管理。详情里的标签可直接进入当前游戏的单标签结果，也可追加到现有筛选。
3. 点卡片主体打开侧栏预览；标题和“完整详情”是真实链接，可在新标签页打开。游戏、筛选、排序、页码、详情标签、滚动与焦点保存在 URL/历史状态中，关闭或返回不会丢失浏览位置。
4. 收藏是“感兴趣”。加入搭配是保存**具体文件及副本**。多文件不会默认全选；可勾选最多三个文件比较。
5. “我的搭配”可以新建、复制、改名、写备注和导出 JSON/TXT；也可导入旧 JSON 清单，校验后保存为新搭配。

搭配只是准备使用的文件清单。未执行安装，也不代表已检查所有冲突；缺少依赖记录不等于无需依赖。

## 整理资料与中文翻译

- MOD 概览或文件行点“整理资料”，修改摘要、说明等；源缓存不变。MOD 概览的“修改记录”支持恢复。
- “资料与设置”可导出当前范围全部资料，也能导入 AI 整理的修改记录，先看合格项和错误再提交。
- “中文翻译”可选取最多 12 个候选 MOD 生成试运行任务包；已有合格译文的字段会跳过，实际待译 MOD 数以包内清单为准。交给 Gemini 时按包内入口说明翻译；回传 JSONL 后先预览再导入。长文分段未齐时只保存进度，不把半篇当成完整说明。
- 保留原文，详情可以切换“中文优先 / 原文 / 双语”。模型名称是外部协作标签，应用本身不调用 Gemini API。

## 备份与恢复

“AI 与任务中心 → 备份”通过 SQLite 在线备份接口同时生成 `catalog.sqlite3`、`work-runtime.sqlite3` 和带 SHA-256 的 `manifest.json`。备份成功后把整个备份目录复制到自己的备份盘；原压缩包和图片仍需另外备份。

旧“资料与设置 → 备份”接口 `/api/backup` 只保存单个目录数据库，不能作为平台配对恢复输入。需要恢复任务、作业和回执时，请使用“AI 与任务中心 → 备份”生成的整套目录。

恢复前先生成当前配对备份，并在任务中心正常停止服务。用固定运行时执行
`.\.runtime\python.exe -X utf8 restore_platform.py 备份目录` 只校验和预览；核对后执行
`.\.runtime\python.exe -X utf8 restore_platform.py 备份目录 --confirm`。不要手工替换任一
数据库或删除 WAL/SHM：恢复工具与服务争用同一生命周期锁，并用
`restore-journal.sqlite3` 在中断后成对重建旧库或新库；无法判定时会阻止启动并保留两套副本。

正式启动固定使用项目内 CPython 3.13.15 x64 / SQLite 3.53.4。首次双击会依据 `runtime-lock.json` 下载、校验并自检官方组件，不会修改系统 Python；离线部署可预先运行 `python tools/bootstrap_runtime.py`。

原盘离线时收藏和搭配保留；移动整个资料目录后，到“游戏资料位置”保存新根目录。重建索引会保留用户资料；找不到的来源会列在 skippedGames。无编号本地文件改名可能导致身份变化，需重新匹配。

## 给 AI 的入口

让新助手先读本指南和 [AI 平台指南](ai-platform-guide.md)；它可以用 `ai.py` 操作
同一份数据，无需截图点击。代码地图在 [architecture.md](architecture.md)。Git 只保存
源码、公开文档和合成示例；运行数据库、令牌、备份和导出不进入 Git。
