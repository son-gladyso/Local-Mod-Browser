# 界面设计规范

本规范约束浏览器界面的视觉与交互取值。新增或修改界面（包括由 AI 生成的改动）都按这里执行；需要偏离时，先改这份文档并写明理由，再改代码。实现集中在 `static/theme.css`（视觉）和 `static/interaction.js` / `static/interaction.css`（交互）。

视觉方向参照 Nexus Mods 的设计语言：近黑底、深灰内容面、经典橙作强调、信息密度高、装饰少。只借鉴设计语言，不使用 Nexus 的样式表、字体、图标或图片。

## 1. 颜色

只用下列令牌（`theme.css` 的 `--nx-*`），不写零散色值，不用渐变做大面积背景，不用发光和毛玻璃。

| 用途 | 令牌 | 值 |
|---|---|---|
| 页面底、顶栏 | `--nx-nav` | `#0f0f10` |
| 带状区域（筛选栏、标签栏、面板） | `--nx-surface-low` | `#1d1d21` |
| 内容面（卡片、详情面板） | `--nx-surface-mid` | `#29292e` |
| 条目头 / 条目体 | `--nx-surface-high` / `--nx-surface-higher` | `#353439` / `#3f3e43` |
| 分隔线 | `--nx-stroke-weak` / `--nx-divider` | 白 10% / `#3c3b40` |
| 正文 / 次要 / 弱化文字 | `--nx-text` / `--nx-text-subdued` / `--nx-text-weak` | `#e1e1e1` / `#a1a1aa` / `#8e8e8e` |
| 强调色 | `--nx-primary`（悬停 `--nx-primary-hover`，焦点 `--nx-primary-focus`） | `#d98f40` |
| 状态 | `--nx-success` / `--nx-warning` / `--nx-danger` | 绿 / 琥珀 / 红 |

强调色只用于：当前位置标记（菜单下划线、标签页顶线）、主操作按钮、计数、勾选态和链接。一屏里同时出现的橙色主按钮不超过一个。

## 2. 间距

以 **4px 为基准**，只用这组值：`4 · 8 · 12 · 16 · 24 · 32 · 48 · 64 · 96`。

- 布局层级（区块之间、页面边距、卡片网格间隙、面板内边距）只用 **8 的倍数**：8、16、24、32、48。
- 4 和 12 只用于控件内部（按钮内边距、图标与文字的间隔、标签之间）。
- 1–3px 只用于描边和位置标记线，不算间距。
- 相关的东西靠得近，不相关的分得开：同一组内 4–8，组与组之间 16–24，区块之间 24–48。不要所有元素等距。

## 3. 字体与字号

- 字体：Inter（拉丁字符，随项目打包，SIL OFL 1.1）+ 系统中文 UI 字体（微软雅黑 UI / 苹方 / Noto Sans CJK）。
- 中文不加字距，不用全大写装饰性小标题；只有极短的拉丁分区标题可加 0.1em 字距。
- 只用下列字号：

| 层级 | 字号 / 字重 | 用在 |
|---|---|---|
| 展示标题 | 40 / 600 | 资料库页头标题 |
| 页面标题 | 30 / 600 | 各页面标题 |
| 区块标题 | 24 / 500 | 文件分组（主文件、可选文件）、面板标题 |
| 条目标题 | 18 / 600 | MOD 卡片标题 |
| 强调正文 | 16 / 400–500 | 顶部菜单、结果数、详情标题行 |
| 正文 | 14 / 400 | 说明、筛选项、按钮 |
| 辅助 | 13 / 400 | 次要说明、标签页、标签 |
| 注释 | 12 / 400–600 | 统计标签、徽标、面包屑 |

小于 12px 的字号不用（中文在 12px 以下难以辨认）。粗体只给标题和小标签，正文、按钮用常规或 500。

## 4. 圆角与阴影

| 级别 | 圆角 | 用在 |
|---|---|---|
| 无 | 0 | 通栏色带、标签栏、菜单项 |
| 小 | 2px | 标签、徽标、封面小图 |
| 常规 | 4px（`--nx-radius`） | 按钮、输入框、卡片、文件条目、下拉菜单 |
| 浮层 | 8px | 对话框、底部提示条 |
| 圆形 | 50% | 只用于状态圆点 |

阴影只给浮在页面上的东西（详情面板、下拉菜单、对话框、提示条、滚动后的顶栏），卡片平时不加阴影。

## 5. 图标

- 只用一套线条图标：16×16 网格，描边 1.5，圆角端点和转角，颜色跟随文字（`currentColor`）。
- 图标定义在 `app.js` 的 `ICONS`（内联 SVG）和 `theme.css` 的图标遮罩（CSS mask）里，新增图标沿用同样的画法。
- 不用 emoji，不用文字符号代替图标（`‹ › × ✓ ↑ +` 等）；不混用面性图标。
- 纯图标按钮必须有 `aria-label`。

## 6. 动效

- 时长 120–250ms，只变颜色、透明度和小幅位移或缩放；不做弹跳、不做循环装饰动画。
- 动效回应用户刚做的动作（按下、悬停、切换、筛选），不主动吸引注意。
- `prefers-reduced-motion: reduce` 时全部关闭，功能不受影响。

## 7. 内容

- 用真实的数据和文案检查布局：长 MOD 名、长作者名、没有图片、没有标签、上千条结果。
- 文案写具体的事实和下一步，不写口号和装饰性副标题；同一件事全站用同一个词。
- 状态用文字说明，颜色只作辅助（色弱用户也要能分辨）。

## 检查清单

改完界面后自查：

- [ ] 新增的颜色都来自第 1 节的令牌
- [ ] 间距都在第 2 节的取值里，布局间距是 8 的倍数
- [ ] 字号都在第 3 节的表里
- [ ] 圆角符合第 4 节的层级
- [ ] 没有 emoji 或文字符号图标
- [ ] 打开“减少动态效果”后功能正常
- [ ] 用长文本、无图片、空结果检查过布局
